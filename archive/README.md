# Project archive

This directory contains material that is no longer part of the active
workflow. It is retained for provenance and possible future reference, but it
is not the current source of truth and it is not part of the workshop upload.

## Contents

- `docs/`: dated reports, superseded protocols, planning notes, and research
  audits.
- `scripts/`: development, renderer-qualification, benchmark-intake, and
  cross-simulator scripts that are not needed by the current paper workflow.
- `configs/`: configuration files with no active source, test, or current-script
  references.
- `notebooks/`: the earlier ML planning notebook.
- `root/`: scratch and planning files that were previously at repository root.
- `reference/`: local reference material used while drafting.
- `private/`: author-kit files and internal notes. This subtree is ignored by
  Git and should not be uploaded.
- `scratch/`: editor metadata and generated bytecode. This subtree is ignored
  by Git and should not be uploaded.

The active source of truth remains the root `README.md`, `src/`, `tests/`,
selected files under `configs/` and `docs/`, and
`submission/aaai27/reviewer_bundle/`.

Raw data, generated results, and local environments were not moved because
current commands refer to their existing paths. Disposable environments,
pytest caches, downloaded reference material, and temporary result folders are
under `private/local/`. The active data and result releases remain in `data/`
and `results/` for pipeline compatibility; they remain private and are
excluded from the reviewer package.
