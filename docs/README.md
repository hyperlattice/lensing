|---|---|
| `codebase_guide.md` | Scientific and software architecture. |
| `dataset_schema.md` | Manifest fields, paths, units, and domain rules. |

| `reliability_study/final/` | Final research card, manuscript, evidence map, and reproducibility statement. |
| `../archive/private/` | Local working notes and authoring material; ignored by Git. |

Historical protocols, planning notes, benchmark audits, and superseded reports
are in [`../archive/README.md`](../archive/README.md).

For workshop submission, upload only the curated files in
`../submission/aaai27/reviewer_bundle/`. Do not upload `docs/`, `results/`,
`data/`, or the private working tree.
