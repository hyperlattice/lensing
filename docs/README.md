# Documentation

The maintained workflow is described by:

- [Study design](study.md): question, arms, budgets and statistical units.
- [Reproduction](reproduction.md): commands, inputs and existing destinations.
- [Data contract](data_contract.md): units, identities, arrays and access boundaries.
- [Rendering](rendering.md): consolidated numerical implementation and qualification.
- [Migration](migration.md): retired workflows, validation and historical checkout.
- [Artifact policy](artifact_policy.md): existing evidence tracking rules.

Other documents in this directory, including reliability-study phases and older
quickstarts, are preserved historical records. Their old commands and configuration
paths apply to their original checkout, not the simplified maintained workflow.
Literature reviews remain background material, not executable specifications.
