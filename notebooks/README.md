# Notebooks

Notebooks are for explanation, planning, and read-only exploration. Keep the
reproducible pipeline in `src/` and versioned configurations in `configs/`.

`ml_implementation_plan_v1.ipynb` is the decision record for the ML roadmap.
It links to the implemented multi-seed benchmark and lists the remaining input,
loss, architecture, robustness, uncertainty, final-holdout, and real-data
phases.
